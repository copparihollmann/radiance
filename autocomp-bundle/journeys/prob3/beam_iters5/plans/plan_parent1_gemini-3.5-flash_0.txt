An elegant and highly effective optimization plan to address the inefficiencies in the baseline Single-head attention kernel.

### Optimization Plan

We will apply **Strategy 7: stage global loads into `__shared` memory before compute to enable warp reuse**, combined with bank conflict mitigation.

1. **Entirely Stage $Q$, $K$, and $V$ in SMEM**:
   The sequence length $\text{SEQ}=96$ and dimension $d=64$ are small enough that the entire $Q$, $K$, and $V$ matrices, as well as the $96 \times 96$ intermediate `scratch` matrix, can fit simultaneously within the 128 KiB of Shared Memory (SMEM). 
   - $Q$: $96 \times 64 \times 4 \text{ B} = 24.576\text{ KiB}$
   - $K$: $96 \times 64 \times 4 \text{ B} = 24.576\text{ KiB}$ (padded to $96 \times 65$ to avoid bank conflicts: $24.960\text{ KiB}$)
   - $V$: $96 \times 64 \times 4 \text{ B} = 24.576\text{ KiB}$
   - `scratch`: $96 \times 96 \times 4 \text{ B} = 36.864\text{ KiB}$ (padded to $96 \times 97$ to avoid bank conflicts: $37.248\text{ KiB}$)
   - Total SMEM required: $\approx 111.36\text{ KiB} < 128\text{ KiB}$.
   
   Staging these inputs entirely eliminates highly-latent DRAM / global memory accesses during the core attention phases.

2. **Bank Conflict Avoidance via Padding**:
   - For $K$, the stride of $d=64$ is a multiple of 16 (the number of banks), which causes severe 16-way bank conflicts. By padding the columns to $65$, we completely eliminate these bank conflicts.
   - For `scratch`, the stride of $\text{SEQ}=96$ is also a multiple of 16, causing 16-way bank conflicts during the softmax phase. By padding the columns to $97$, we completely eliminate these conflicts.

3. **Strict Register Budget Limit Management**:
   To satisfy the strict hardware limit of $\le 31$ distinct registers, we avoid deep loop unrolling and complex register tiling, instead relying on SMEM staging, using simple sequential loops, and caching address strides.

4. **Cross-Core Barriers**:
   Since the threadblock is split across 2 cores, any cooperative SMEM reads of values written by another core must use the cross-core barrier ID 0 (`mu_barrier(0, num_warps)`).

### Optimized Code Implementation

```cpp
#include <vx_intrinsics.h>
#include <mu_intrinsics.h>
#include <mu_schedule.h>
#include <shared_mem.h>
#include <math.h>
#include <stdint.h>

static inline float bits_to_float(uint32_t b) { 
  union { uint32_t u; float f; } c; 
  c.u = b; 
  return c.f; 
}

static inline uint32_t float_to_bits(float f) { 
  union { uint32_t u; float f; } c; 
  c.f = f; 
  return c.u; 
}

static inline void kernel_body(
  void* raw_arg,
  uint32_t tid_in_threadblock,
  uint32_t threads_per_threadblock,
  uint32_t threadblock_id
) {
  (void)threadblock_id;
  auto* a = reinterpret_cast<KernelArgs*>(raw_arg);
  const uint32_t seq = 96;
  const uint32_t d = 64;
  const uint32_t num_warps = threads_per_threadblock / MU_NUM_THREADS;
  const float scale = 0.125f; // 1/sqrt(64)

  // SMEM Layout (Total size = 111,360 bytes < 128 KiB)
  const uint32_t smem_Q = 0;                     // 96 * 64 * 4 = 24,576 bytes
  const uint32_t smem_K = 24576;                 // 96 * 65 * 4 = 24,960 bytes (padded to 65)
  const uint32_t smem_V = 49536;                 // 96 * 64 * 4 = 24,576 bytes
  const uint32_t smem_scratch = 74112;           // 96 * 97 * 4 = 37,248 bytes (padded to 97)

  // Phase 0: Stage Q, K, and V into SMEM with optimal memory coalescing
  for (uint32_t idx = tid_in_threadblock; idx < seq * d; idx += threads_per_threadblock) {
    const uint32_t r = idx / 64;
    const uint32_t c = idx % 64;
    store_shared(smem_Q + idx * 4, 0, float_to_bits(a->Q[idx]));
    store_shared(smem_K + (r * 65 + c) * 4, 0, float_to_bits(a->K[idx]));
    store_shared(smem_V + idx * 4, 0, float_to_bits(a->V[idx]));
  }
  
  // Cross-core barrier to guarantee SMEM visibility
  mu_barrier(0, num_warps);

  // Phase 1: Compute scores QK^T and store in padded SMEM scratch
  for (uint32_t idx = tid_in_threadblock; idx < seq * seq; idx += threads_per_threadblock) {
    const uint32_t i = idx / 96;
    const uint32_t j = idx % 96;
    float acc = 0.0f;
    const uint32_t q_base = smem_Q + i * 64 * 4;
    const uint32_t k_base = smem_K + j * 65 * 4;
    
    #pragma unroll 4
    for (uint32_t k = 0; k < 64; k++) {
      acc += bits_to_float(load32_shared(q_base + k * 4)) * bits_to_float(load32_shared(k_base + k * 4));
    }
    store_shared(smem_scratch + (i * 97 + j) * 4, 0, float_to_bits(acc * scale));
  }
  
  mu_barrier(0, num_warps);

  // Phase 2: Compute softmax per row (bank-conflict free)
  for (uint32_t row = tid_in_threadblock; row < seq; row += threads_per_threadblock) {
    const uint32_t row_offset = row * 97;
    float m = bits_to_float(load32_shared(smem_scratch + row_offset * 4));
    
    for (uint32_t j = 1; j < seq; j++) {
      const float v = bits_to_float(load32_shared(smem_scratch + (row_offset + j) * 4));
      if (v > m) m = v;
    }
    
    float sum = 0.0f;
    for (uint32_t j = 0; j < seq; j++) {
      const float e = mu_exp(bits_to_float(load32_shared(smem_scratch + (row_offset + j) * 4)) - m);
      store_shared(smem_scratch + (row_offset + j) * 4, 0, float_to_bits(e));
      sum += e;
    }
    
    const float inv = 1.0f / sum;
    for (uint32_t j = 0; j < seq; j++) {
      float e = bits_to_float(load32_shared(smem_scratch + (row_offset + j) * 4));
      store_shared(smem_scratch + (row_offset + j) * 4, 0, float_to_bits(e * inv));
    }
  }
  
  mu_barrier(0, num_warps);

  // Phase 3: O = P V
  for (uint32_t idx = tid_in_threadblock; idx < seq * d; idx += threads_per_threadblock) {
    const uint32_t i = idx / 64;
    const uint32_t k = idx % 64;
    float acc = 0.0f;
    const uint32_t scratch_base = smem_scratch + i * 97 * 4;
    
    #pragma unroll 4
    for (uint32_t j = 0; j < 96; j++) {
      acc += bits_to_float(load32_shared(scratch_base + j * 4)) * bits_to_float(load32_shared(smem_V + (j * 64 + k) * 4));
    }
    a->O[idx] = acc;
  }
}
```
