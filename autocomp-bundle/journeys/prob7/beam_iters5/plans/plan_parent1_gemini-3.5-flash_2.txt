### Optimization Plan

We will apply **Strategy 1: cache reused data in local memory instead of reloading from main memory** to dramatically reduce execution time.

#### Inefficiencies in the Original Code:
- **Redundant DRAM Reads for $K$:** In Phase 1, each of the 128 threads computes dot products for 128 columns, loading the key vector $K$ from DRAM each time. This results in $128 \times 128 \times 64 = 1,048,576$ FP32 loads from DRAM for $K$.
- **Redundant DRAM Reads for $V$:** In Phase 3, each thread loads the value vector $V$ from DRAM repeatedly when computing the output $O$, resulting in another $1,048,576$ FP32 loads from DRAM.

#### Optimization Details:
1. **Cooperative SMEM Staging:**
   - We allocate a portion of the 128 KiB Shared Memory (SMEM) starting at address `0x0` for $Q$ (32 KiB) and $K$ (32 KiB).
   - Before Phase 1, all 128 threads cooperatively load $Q$ and $K$ from global memory into SMEM.
   - We execute a cross-core barrier `mu_barrier(0, nw)` to ensure all SMEM writes are visible SoC-wide before calculation.
2. **Phase 1 Execution:**
   - Instead of reading from DRAM, threads compute the score matrix by reading from the fast `s_Q` and `s_K` SMEM arrays.
3. **Phase 3 Staging & Execution:**
   - Since $Q$ and $K$ are no longer needed, we reuse the SMEM starting at address `0x0` to cache the $V$ matrix (32 KiB).
   - Threads cooperatively load $V$ into SMEM, synchronize with `mu_barrier(0, nw)`, and perform the Phase 3 gemm computation entirely out of SMEM.

This reduces the DRAM loads for $K$ and $V$ by **128x**, completely eliminating the memory-bound bottleneck while strictly keeping register usage $\le 31$ per thread.

### Optimized Code

```cpp
#include <vx_intrinsics.h>
#include <mu_intrinsics.h>
#include <mu_schedule.h>
#include <shared_mem.h>
#include <stdint.h>

struct KernelArgs {
  __global float* Q;
  __global float* K;
  __global float* V;
  __global float* scratch;
  __global float* O;
  uint32_t seq;
  uint32_t d;
};

static inline void kernel_body(
  void* raw_arg,
  uint32_t tid_in_threadblock,
  uint32_t threads_per_threadblock,
  uint32_t threadblock_id
) {
  (void)threadblock_id;
  auto* a = reinterpret_cast<KernelArgs*>(raw_arg);
  const uint32_t seq = a->seq;
  const uint32_t d = a->d;
  const uint32_t nw = threads_per_threadblock / MU_NUM_THREADS;

  // Shared Memory pointers (total size: 64 KB for Q and K)
  __shared float* const s_Q = reinterpret_cast<__shared float*>(0x0);
  __shared float* const s_K = s_Q + 8192; // 8192 floats = 32 KB offset

  // Phase 1: Cache Q and K in SMEM, then compute S
  for (uint32_t idx = tid_in_threadblock; idx < seq * d; idx += threads_per_threadblock) {
    s_Q[idx] = a->Q[idx];
    s_K[idx] = a->K[idx];
  }
  mu_barrier(0, nw); // Cross-core barrier for cooperative SMEM loads

  for (uint32_t i = tid_in_threadblock; i < seq; i += threads_per_threadblock) {
    const __shared float* qi = s_Q + i * d;
    for (uint32_t j = 0; j < seq; j++) {
      const __shared float* kj = s_K + j * d;
      float acc = 0.0f;
      for (uint32_t k = 0; k < d; k++) {
        acc += qi[k] * kj[k];
      }
      a->scratch[i * seq + j] = acc * 0.125f;
    }
  }
  mu_barrier(0, nw);

  // Phase 2: Row softmax in place
  for (uint32_t i = tid_in_threadblock; i < seq; i += threads_per_threadblock) {
    __global float* sp = a->scratch + i * seq;
    float m = sp[0];
    for (uint32_t j = 1; j < seq; j++) {
      if (sp[j] > m) {
        m = sp[j];
      }
    }
    float sum = 0.0f;
    for (uint32_t j = 0; j < seq; j++) {
      const float e = mu_exp(sp[j] - m);
      sp[j] = e;
      sum += e;
    }
    const float inv = 1.0f / sum;
    for (uint32_t j = 0; j < seq; j++) {
      sp[j] *= inv;
    }
  }
  mu_barrier(0, nw);

  // Phase 3: Cache V in SMEM, then compute O (reusing the start of SMEM)
  __shared float* const s_V = reinterpret_cast<__shared float*>(0x0);
  for (uint32_t idx = tid_in_threadblock; idx < seq * d; idx += threads_per_threadblock) {
    s_V[idx] = a->V[idx];
  }
  mu_barrier(0, nw); // Cross-core barrier for cooperative SMEM loads

  for (uint32_t i = tid_in_threadblock; i < seq; i += threads_per_threadblock) {
    const __global float* sp = a->scratch + i * seq;
    for (uint32_t k = 0; k < d; k++) {
      float acc = 0.0f;
      for (uint32_t j = 0; j < seq; j++) {
        acc += sp[j] * s_V[j * d + k];
      }
      a->O[i * d + k] = acc;
    }
  }
}
```
